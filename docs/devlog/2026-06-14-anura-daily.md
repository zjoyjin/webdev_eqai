# Anura 本地化测量

## 今日完成

- 完成了 Anura 本地网站的基本功能闭环：准备测量、打开摄像头、面部检测、手动开始、采集进度、后运算、结果展示等主流程已经具备。
- 对照 demo 和线上参考站点，确认了更符合用户直觉的测量流程，并把本地版本调整为更接近参考体验：用户先准备摄像头，调整面部位置和光线后，再手动开始测量。
- 保留了本地项目的核心架构目标：前后端分拆，DeepAffex 相关凭据和 token 处理放在服务端，前端只走本地 API，不直接暴露关键凭据。
- 修复了多处影响体验的问题：准备阶段不会自动开始测量；准备后再次点击可以关闭摄像头；采集进度改为按秒显示；读秒结束后进入后运算；摄像头预览改为镜像，更符合用户自我调整习惯。
- 完成了结果展示的第一轮整理：心率、呼吸率等核心指标进入统一展示区；信噪比从普通结果中移出，改为放到右下角质量区域，并显示信噪比指数。
- 针对结果数值异常，开始把归一化逻辑从前端展示层下沉到 API/shared 数据契约层，避免只靠改小数点和单位掩盖真实数据问题。

## 今日结论

今天的主要成果不是 UI 微调，而是项目已经具备了本地化 Anura 测量网站的基本可用形态，并且拿到了继续验证真实测量数据所需的 token 链路。

当前方向仍然是：体验对齐 demo，架构坚持本地服务端承接敏感凭据和数据处理。
