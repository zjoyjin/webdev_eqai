# EQAI MVP 产品体验

## 产品体验路径

用户可以从 EQAI 首页进入评估目录，查看评估详情，登录后完成题目，保存结果，并在“我的记录”中回看历史评估。

## 主要产品进展

- 评估目录和评估详情可用：目录展示已启用评估，并支持按工作、个人、儿童、宠物等入口进入。
- 作答和结果保存流程可用：登录用户可以开始评估，完成题目后保存结果，并进入结果页查看总分、平均分、完成时间、答题数量和维度摘要。
- “我的记录”可用：用户可以查看已开始或已完成的评估，未完成记录可以继续，已完成记录可以查看结果。
- 登录体验更清楚：导航会根据登录状态切换，未登录显示“登录”，登录后显示“我的记录”。
- 中文评估页面更干净：不再同时混排中英文评估名、维度名和题目内容。
- 首页内容按当前口径校准：首屏保持 logo 视觉，并保留当前需要的 mission 图片占位和宽幅 banner 图片占位。
- 全站视觉统一：评估目录、详情、作答、结果、我的记录、登录、联系、关于、隐私、条款和评审页统一到首页视觉方向。
