# EQAI

## 当前状态

- Vercel 英文站点当前可访问。
- 前端应用已完成线上部署。
- 测评数据相关能力已完成基础连通性验证。
- 联系表单已完成一次线上提交验证。
- 当前线上数据服务采用云端 Supabase。

## 网站功能

- 首页和基础品牌展示。
- 评估目录入口，可展示已启用的评估。
- 评估详情页，可展示评估介绍、适用维度和非诊断边界说明。
- 登录入口，导航会根据登录状态展示“登录”或“我的记录”。
- 登录后作答流程，支持用户开始评估、完成题目并保存结果。
- 结果页，展示总分、平均分、完成时间、答题数量和维度摘要。
- “我的记录”，支持查看已开始或已完成的评估记录。
- 联系页，支持提交联系表单。
- 关于、隐私、条款、评审页等基础内容页面。
- 测评目录数据服务，支持按测评模块、测评组、测评维度读取数据。

## 数据与后端状态

- 本周最终采用云端 Supabase 作为数据服务，不再把完整 Supabase 自托管服务部署在当前阿里云 ECS 上。
- 这个调整主要是为了降低服务器资源压力，并减少数据库运维负担。当前应用已经接入云端 Supabase，联系表单和测评目录相关数据能力完成了基础验证。

# Anura

## 网站功能

- 摄像头采集入口，可进入 camera 测试流程。
- 浏览器端人脸检测和姿态点处理能力。
- DFX WASM 本地采集和 chunk 生成能力。
- 测量 UI，包括测量状态、约束提示、倒计时和结果展示思路。
- 前端通过同源 API 与后端交互，不直接暴露 DeepAffex 原始凭据。
- 后端负责 DeepAffex 相关凭据托管、SDK config 获取、measurement 创建、chunk 转发和 result polling。
- 本地数据记录能力，用于保存 session、measurement、chunk metadata 和 audit events。
- Mock 测量闭环已经验证，可完成 session、measurement、chunk 上传和 results 返回的模拟流程。

- 当前还没有部署，主要原因是项目整体需要后端能力配合，暂时不适合只部署前端版本作为正式体验入口。
